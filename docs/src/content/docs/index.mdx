## Why FetchQuack?

<CardGrid stagger>
	<Card title="🌐 Universal Runtime">
		Write once, run everywhere. Browser, Node.js, Bun, and Deno. Zero configuration, zero platform-specific code.
	</Card>
	<Card title="🌊 True Streaming">
		Not just promises—real streaming for text and binary data. AI chat responses, logs, file downloads. It just works.
	</Card>
	<Card title="📡 SSE Done Right">
		Full Server-Sent Events spec with auto-reconnect, Last-Event-ID, and exponential backoff. Unlike EventSource, supports POST.
	</Card>
	<Card title="⏳ Progress Everywhere">
		Upload and download progress on all platforms. No hacky workarounds. Platform-optimized under the hood.
	</Card>
	<Card title="🔄 Powerful Interceptors">
		Auth, logging, retry, custom logic. Clean middleware API with dependency injection support (yes, even in Angular).
	</Card>
	<Card title="🪶 Tiny & Fast">
		~4KB gzipped. Zero runtime dependencies. TypeScript-first with complete type safety.
	</Card>
</CardGrid>

## See It in Action

<Tabs>
<TabItem label="Basic Request">

```typescript
import { HttpClient } from 'fetchquack';

const client = new HttpClient();

// Simple, typed requests
const user = await client.fetch<User>({
  method: 'GET',
  url: '/api/users/1'
});

console.log(user.name);
```

</TabItem>
<TabItem label="AI Streaming">

```typescript
// Stream AI responses chunk by chunk
let response = '';

await client.fetchStream({
  method: 'POST',
  url: '/api/ai/chat',
  body: { prompt: 'Explain HTTP streaming' },
  decodeToString: true,
  onData: (chunk) => {
    response += chunk;
    updateUI(response); // Real-time updates
  }
});
```

</TabItem>
<TabItem label="Server-Sent Events">

```typescript
// SSE with auto-reconnect
await client.sse({
  method: 'GET',
  url: '/api/events',
  autoReconnect: true,
  parseJson: true,
  onEvent: (event) => {
    console.log(event.data);
  }
});
```

</TabItem>
<TabItem label="Progress Tracking">

```typescript
// Monitor upload/download progress
await client.fetch({
  method: 'POST',
  url: '/api/upload',
  body: file,
  onUploadProgress: (p) => {
    progressBar.style.width = `${p.percentage}%`;
  }
});
```

</TabItem>
<TabItem label="Angular">

```typescript
// Angular with RxJS
@Component({...})
export class ChatComponent {
  private http = inject(NgxHttpClient);
  response = signal('');

  streamChat(prompt: string) {
    this.http.fetchStream({
      method: 'POST',
      url: '/api/ai/chat',
      body: { prompt },
      decodeToString: true
    }).pipe(
      takeUntilDestroyed()
    ).subscribe(chunk => {
      this.response.update(r => r + chunk);
    });
  }
}
```

## Install & Go

```bash
npm install fetchquack
```

That's it. No configuration. No setup. Just import and use.

```typescript
import { HttpClient } from 'fetchquack';

const client = new HttpClient();
const data = await client.fetch({ method: 'GET', url: '/api/data' });
```
